# Пачки вопросов для приложения «Викторина»

Здесь лежат пачки вопросов, которые приложение скачивает само. Приложение
«Викторина» для незрячих читает их по прямым ссылкам, без авторизации, поэтому
репозиторий публичный. Ничего секретного в вопросах нет, но и править их может
только владелец репозитория.

## Что тут лежит

- `index.json` — список пачек: имя файла, тема, версия, число вопросов.
- `packs/*.json` — сами пачки, по файлу на тему.
- `wiki/index.json` и `wiki/packs/*.json` — второй склад, собранный из
  Викиданных программой `tools/wiki-packs.py`. Приложение читает его, когда в
  «Сменить тему» выбрана «Вики»; свои пачки при этом остаются на месте, в корне.

Два склада не смешиваются: у них разные папки, разные списки и разные номера
вопросов. Приложение ходит в тот, который выбран, и держит скачанное из каждого
отдельно.

## Формат пачки

```json
{
  "pack": "obshee-1",
  "category": "Общая эрудиция",
  "questions": [
    {"id": 1001, "q": "Сколько дней в високосном году?",
     "answers": ["366 дней", "365 дней", "364 дня", "367 дней"],
     "correct": 0}
  ]
}
```

Ответов всегда ровно четыре, `correct` — номер верного ответа, считая с нуля.
Вопрос с тремя ответами или с номером вне границ приложение отбросит, а не
покажет без верного ответа.

## Номера вопросов

Номер вопроса — это память: телефон помнит, что уже спрашивал, и по номеру не
спрашивает снова. Поэтому номера не переиспользуются никогда. Диапазоны:

- 1000–1999 — общая эрудиция
- 2000–2999 — массаж и анатомия
- 3000–3999 — спорт и тренировки
- 4000–4999 — история России
- 5000–5999 — география
- 6000–6999 — животные и природа
- 7000–7099 — авто и мото
- 7100–7199 — психология
- 7200–7299 — древняя история
- 7300–7399 — экономика
- 7400–7499 — логика
- 7500–7599 — поговорки
- 7600–7699 — писатели
- 7700–7799 — следующая тема

Внутри диапазона номера идут подряд по мере добавления вопросов.

Вики-пачки нумеруются отдельно, тысяча на тему:

- 8000–8999 — страны и столицы
- 9000–9999 — страны и деньги
- 10000–10999 — части света
- 11000–11999 — химические знаки
- 12000–12999 — химические номера
- 13000–13999 — картины
- 14000–14999 — кино
- 15000–15999 — горы
- 16000–16999 — вулканы
- 17000–17999 — спутники планет
- 18000–18999 — языки стран
- 19000–19999 — столицы (страна по столице)
- 20000–20999 — музеи
- 21000–21999 — писатели
- 22000–22999 — реки
- 23000–23999 — острова
- 24000–24999 — озёра
- 25000–25999 — национальные парки
- 26000–26999 — песни
- 27000–27999 — следующая тема

Диапазоны разные не для порядка, а по делу: память о заданных вопросах у обоих
складов общая, и один и тот же номер в двух складах означал бы, что второй
вопрос никогда не прозвучит.

## Как править

Текст вопроса меняется на месте, номер остаётся прежним: тогда новый текст
придёт на телефон вместо старого. Новая версия вопроса — это увеличенная
`version` в `index.json`: по ней приложение понимает, что пачку пора перечитать.

Если вопрос оказался неудачным, его лучше исправить, а не удалять: удалённый
просто исчезнет, а память о том, что он спрашивался, уже не отменить.
